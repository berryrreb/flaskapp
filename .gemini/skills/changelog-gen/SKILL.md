# Skill: Gestión del Historial de Versiones (changelog-gen)

Esta habilidad proporciona el estándar para registrar cambios de software de forma limpia y transparente en `CHANGELOG.md` basado en "Keep a Changelog".

## 📝 Directrices:
1.  **Secciones Semánticas**: Clasifica los cambios del proyecto bajo las siguientes categorías de forma rigurosa:
    - `Added` (Para nuevas características).
    - `Changed` (Para cambios en lógica existente).
    - `Deprecated` (Para funciones pronto a ser removidas).
    - `Removed` (Para características eliminadas).
    - `Fixed` (Para parches de bugs).
    - `Security` (Para mitigaciones de vulnerabilidades).
2.  **Formato de Versión**: Sigue el estándar de Versionado Semántico (SemVer) `MAJOR.MINOR.PATCH` (ej. `v1.1.0`).
